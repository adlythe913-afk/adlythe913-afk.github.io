Optimus Tech Automation

Privacy & data use

This notice covers the private Optimus Tech Automation publishing integration and this documentation website.

Access to Google and YouTube data

Using the owner's authorized OAuth grant, the application reads channel identifiers and video metadata, uploads owner-approved video bytes and metadata, and checks the resulting channel, title and visibility. Its requested permissions are YouTube read-only and upload access. It does not request Gmail, contacts or payment data.

Purpose and limits

Google API data is used to provide the owner-requested channel checks, review and approved publishing functions described on this site. The publishing subsystem does not sell this data, use it to build advertising profiles or build a model-training dataset. Its handling of Google API data is subject to the Google API Services User Data Policy, including the Limited Use requirements.

Local storage and retention

n8n stores the OAuth credential encrypted in the owner's local profile. The local publishing broker may read a protected, temporary export of that exact credential; the temporary plaintext file is removed after the operation. Credentials are not included in public workflow exports, review notices or this website.

The local ledger stores draft metadata, media paths and SHA256 fingerprints, approval references and expiry, upload-attempt state and provider video identifiers. Original media remains in the owner's local archive. Records are retained until the owner deletes them; this version has no automatic deletion schedule.

Sharing and service providers

Google receives the authorized API requests and any approved uploaded video. Owner-enabled Telegram review uses the existing private bot conversation for draft and status information. An owner-enabled assistant may receive review and operational context under the owner's configuration. OAuth secrets are not included in these review messages. Google, Telegram and any selected assistant provider have their own data practices that also apply.

Revocation, deletion and owner control

The owner can revoke access through Google Account permissions, remove the local n8n credential and delete local drafts or audit records. Revoking OAuth access does not itself delete local archives or videos already uploaded to YouTube. Those require a separate owner action. Each upload approval expires and applies only to its saved file, metadata, channel and visibility.

This is a private instance without public registration. The operator uses the existing private review conversation and the support contact shown on the Google OAuth consent screen to handle questions or data requests.

Website hosting

These static pages are hosted on GitHub Pages and contain no advertising or analytics scripts and no sign-in or data-entry forms. GitHub processes visitor connection information, including IP addresses for security, under the GitHub Privacy Statement.
