Optimus Tech Automation

A local publishing assistant for the Optimus Tech YouTube channel. It connects saved video drafts, n8n automation and the owner's private Telegram review conversation.

Approval is per video. Connecting a Google account does not authorize publication. Public uploads and automatic visibility changes are not enabled in this publishing subsystem.

What the integration does

  1. Checks the connected YouTube channel using Google OAuth and read-only API requests.
  2. Saves the exact video fingerprint, title, description, audience choice and requested nonpublic visibility for review.
  3. Requires a separate, time-limited owner approval before a new upload.
  4. Can upload approved content as Private or Unlisted, then checks the provider's returned video metadata.
  5. Records attempts and stops automatic retries when an outcome is uncertain, preventing duplicate uploads.

Private operation, public documentation

The application runs on the owner's Windows computer. This website explains the integration; it does not provide public registration, account sign-in or a video-upload form.

The YouTube permissions requested are youtube.readonly and youtube.upload. The application does not request Gmail, contacts or payment permissions.

Read the privacy and data-use notice and operational terms. The associated educational channel is Optimus Tech.
